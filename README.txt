THE AI BUSINESS GUIDE - STARTER WEBSITE

Contents:
- index.html: homepage
- ai-tools.html, automation.html, crm.html, productivity.html, website-tools.html: category landing pages
- about.html, contact.html, affiliate-disclosure.html, privacy.html: starter information/legal pages
- assets/style.css: design and responsive styling
- assets/script.js: small homepage script

HOW TO ADD TO GITHUB:
1. Open your GitHub repository.
2. Click Add file > Upload files.
3. Extract this ZIP on your computer first.
4. Upload the contents inside the extracted folder (not the outer folder itself).
5. Commit changes to the main branch.

IMPORTANT BEFORE PUBLIC LAUNCH:
- Replace YOUR-EMAIL@example.com on contact.html with your business email.
- Replace the example canonical URL in index.html once you own a domain.
- Review and complete privacy/legal pages for your actual setup and target countries.
- The sample category copy is a starting point, not finished SEO articles.
- Do not add affiliate links until you join programs and verify their current terms.
- The website uses Bootstrap and Google Fonts via external CDNs.
